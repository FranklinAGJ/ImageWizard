
🪄 Streamlit Image Enhancer
A simple yet powerful AI-powered image enhancement web app built with Streamlit and Pillow (PIL).
Easily upload an image, adjust its brightness, contrast, sharpness, and color, preview changes live, and download your enhanced result — all in one sleek dark-themed interface.
 
🚀 Features
•	Upload images (.jpg, .jpeg, .png)
•	Adjust:
o	Brightness
o	Contrast
o	Sharpness
o	Color
•	Real-time preview (before & after comparison)
•	Download the enhanced image
•	Modern dark theme UI
•	Built using Streamlit and Pillow
 
🧰 Tech Stack
•	Python 3.x
•	Streamlit
•	Pillow (PIL)
•	HTML & CSS (for custom styling)
 
🖥️ Installation and Setup
1.	Clone the repository
bash
git clone https://github.com/<your-username>/streamlit-image-enhancer.git
cd streamlit-image-enhancer
2.	Install dependencies
bash
pip install -r requirements.txt
3.	Run the app
bash
streamlit run ImageWizard.py
4.	Open your browser at:
text
http://localhost:8501

text

🌐 Deployment
Deploy easily on Streamlit Cloud:
1.	Push your project to GitHub
2.	Go to Streamlit Cloud
3.	Click Deploy an app → Connect to GitHub
4.	Select your repository and set entry file as app.py
5.	Click Deploy 🎉
Your live app will be available at:
text
https://<your-username>-streamlit-image-enhancer.streamlit.app
